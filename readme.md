## Descripción del Proyecto
Este proyecto es una solución de consultoría de datos que analiza el inventario de cinco sucursales en El Salvador. El sistema:
1. Carga un dataset de productos desde un archivo CSV utilizando **Pandas**.
2. Agrupa y procesa la información de existencias por sucursal.
3. Despliega una interfaz gráfica de usuario (GUI) construida con **PyQt5**.
4. Muestra un gráfico de barras integrado creado con **Matplotlib** para visualizar los volúmenes operativos.

## Requisitos
Es necesario tener Python instalado. Se recomienda ejecutar este proyecto dentro de un entorno virtual.
Para instalar todas las dependencias necesarias, ejecuta el siguiente comando en la terminal:
\`\`\`bash
pip install -r requirements.txt
\`\`\`

## Instrucciones de Uso
Una vez instaladas las dependencias, asegúrate de estar en el directorio del proyecto y ejecuta el script principal:
\`\`\`bash
python Parcial.py
\`\`\`
Esto abrirá la ventana con el dashboard de inventario.
